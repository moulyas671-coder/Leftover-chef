# 🍃 Leftover Chef

**Cook What Expires First – Reduce Food Waste!**

## About
Leftover Chef is a web-based application that helps users manage food inventory, track expiry dates and find recipes using available ingredients. Its main goal is to reduce household food wastage.

## Features Implemented
- Add and manage food items.
- Track food expiry dates.
- Highlight items expiring soon.
- Suggest up to three matching recipes.
- Display recipe ingredients and instructions.
- Fetch food and recipe images.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Indian Food Recipe Dataset
- Unsplash API

## Future Enhancements
- OCR-based receipt and food-label scanning.
- NLP-based expiry-date recognition.
- Food donation section.
- Food waste tracker (Guilt Area).

## How to Run
1. Install Node.js.
2. Install backend dependencies using `npm install`.
3. Add your Unsplash API key to the backend `.env` file.
4. Start the backend using `node server.js`.
5. Open `index.html` using Live Server.

## Project Goal
To reduce food waste by helping people use available food before it expires.
